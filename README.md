# IOCL Petrol Pump Scraper

Python project for collecting and processing Indian Oil Corporation Limited (IOCL) petrol pump location data.

## Project Contents

This repository includes the Python source files and the sample data files copied from the original project folder.

## Requirements

- Python 3.9 or later (adjust if the project requires a specific version)
- Python packages required by the scraper

## Setup

1. Clone this repository.
2. Open a terminal in the project folder.
3. Install the required dependencies if a `requirements.txt` file is available:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the relevant Python scraper script.

## Sample Data

Sample files included in this repository are intended for testing and demonstration. Check the source and data licensing terms before reuse.
